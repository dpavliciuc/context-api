# context-api

## Context API projects.

This is a practice workspace for context API along with other API's.

# How to Set-Up the projects

## Step 1 Downloading the project

- Download the project as a .zip file `or` make sure git is installed by running `git --version`, if it is, copy the project URL, then use the command `git clone URL` to clone the project in the current folder.

## Step 2 Accessing the project

- Run the command `cd folder-name` to access the folder.

## Step 3 Installing the project

- Check if `npm` is installed by running `npm --version` then install the project by executing `npm install`.

## Step 4 Running the project

- Run the project by executing `npm start`.
